# 气数

> 一个人与一个国家，在不知道下一页会发生什么的时候，还剩多少种选择。

**气数（Qishu）** 是一个长期、开放、可修订的历史与现实研究写作项目。

这里的“气数”不是预言，也不是给王朝或国家计算寿命。它只是一个文学性的总问题：

**当外部环境不可控、旧办法开始失效时，一个人或一个国家还拥有多少资源、韧性、纠错能力与现实可行的选择？**

项目从中国王朝史出发，进入世界大国史与专题机制研究，之后再把同一套方法用于当代国家；最后回到个人：人在时代之中，如何保存自己的余地。

## 五条研究路径

- **王朝**：中国历代王朝如何积累力量，又如何失去选择。
- **世界**：大国、帝国与现代国家如何衰退、转型或重生。
- **机制**：财政、军政、人口、制度、技术、债务、国家能力、社会预期等。
- **当代**：研究今天的国家，尤其中国；不预设盛衰结论，不替任何政治选择背书。
- **人生**：时代无法选择时，个人怎样保存健康、技能、信用、财富与重新开始的能力。

## 出版模型

本仓库是《气数》的**研究与内容单一真相源**，不是最终阅读界面。

- **GitHub**：研究室与编辑部。保存问题、资料、竞争解释、正文母稿、修订历史。
- **tomz.io**：完整阅读版。正文之外可展开研究札记、资料、争议与版本记录。
- **微信公众号**：大众传播版。保持事实与结论一致，但允许更适合移动阅读的标题、节奏和排版。
- **未来书稿**：从长期公开研究中重新编辑，而不是把网页文章机械装订。

同一事实不维护三份“真相”。渠道版本从同一研究母稿派生。

## 原则

1. 权威资料优先，关键事实必须可追溯。
2. 事实、解释、判断、推测分开。
3. 主动寻找反证与竞争解释，不为既有观点搜证。
4. 当代政治与国家问题不预设立场，不给政治选择做排名、推荐或结果预测。
5. 允许修改观点，并保留修改发生过的痕迹。
6. 对话先于成稿。重要文章必须经过充分提问、研究、反问与补证。
