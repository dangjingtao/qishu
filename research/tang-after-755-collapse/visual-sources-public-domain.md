# Visual Sources｜可复用公版 / 开放授权素材候选

对应 Issue：#23  
用途：为后续文章提供可核验的历史图像来源。  
原则：**图像只提供历史氛围或地理辅助，不替代史料证据。**

> 优先记录 Wikimedia Commons 的文件页，而不是只保存图片直链。  
> 文件页包含来源、作者、许可与原始文件下载地址，正式使用时应保留出处和许可说明。

## 1. 《虢国夫人游春图》／Tang court spring outing

**用途建议：**文章开头或“盛唐为何令人觉得繁荣”部分，用作盛唐上层生活与视觉文化的时代氛围，不作为经济繁荣统计证据。

- Commons：
  https://commons.wikimedia.org/wiki/File:Spring_Outing_of_the_Tang_Court.jpg
- 作品：传统归张萱（唐，8 世纪）
- 状态：Public Domain / PD-Art
- Commons 说明：底层二维艺术作品已进入公版，美国亦按 Commons 标注为公版。

### 注意

它表现的是宫廷 / 贵族生活，不能用来代表普通唐人的生活水平。

## 3. 1935 年《唐朝 700 年疆界图》

**用途建议：**如果需要一张老历史地图作为视觉资料，可与现代 742 图交叉参考。

- Commons：
  https://commons.wikimedia.org/wiki/File:The_T%27ang_Dynasty_618-906_AD_--_Boundaries_of_700_AD.jpg

## 6. 黄巢像（明刻《残唐五代史演义》）

**用途建议：**黄巢章节人物视觉，但必须写清它不是唐代写真。

- Commons：
  https://commons.wikimedia.org/wiki/File:Huang_Chao.jpg
- 图像来源：明刻《残唐五代史演义》
- 创作时间：1644 年以前
- 作者：佚名
- 状态：Public Domain（Commons 标注中国及美国公版）

### 必须写的图注

> 明代刻本中的黄巢想象像，并非唐代同时代肖像。

否则普通读者很容易误认为“这是黄巢本人画像”。

## 11. 卫贤《闸口盘车图》（五代）

**用途建议：**不用于证明唐亡原因；可作为“政治秩序断裂以后，经济和技术生活并没有停止”的尾声视觉候选。

- Commons：
  https://commons.wikimedia.org/wiki/File:Water_Mill_(%E9%97%B8%E5%8F%A3%E7%9B%98%E8%BD%A6%E5%9B%BE)_by_Wei_Xian_%E5%8D%AB%E8%B4%A4_(Five_Dynaties).png
- 作品：卫贤《闸口盘车图》
- 年代：五代
- Commons 来源指向：上海博物馆
- 底层作品：Public Domain
- Commons 文件页另有结构化授权字段，正式使用时仍应以馆方 / 文件页当前许可为准。

### 为什么它有意思

如果文章最后落在：

> 一个王朝死了，不等于社会、技术、市场和人的生活一起归零。

这张图的意义比再放一张战争地图更好。

它能把《气数》从“王朝寿命”重新带回：
- 制度会死；
- 能力会迁移；
- 新秩序会从旧秩序留下的技术、人口、市场和组织中继续生长。
