# Visual Sources｜可复用公版 / 开放授权素材候选

对应 Issue：#23  
用途：为后续文章提供可核验的历史图像来源。  
原则：**图像只提供历史氛围或地理辅助，不替代史料证据。**

> 优先记录 Wikimedia Commons 的文件页，而不是只保存图片直链。  
> 文件页包含来源、作者、许可与原始文件下载地址，正式使用时应保留出处和许可说明。

---

## 1. 《虢国夫人游春图》／Tang court spring outing

**用途建议：**文章开头或“盛唐为何令人觉得繁荣”部分，用作盛唐上层生活与视觉文化的时代氛围，不作为经济繁荣统计证据。

- Commons：
  https://commons.wikimedia.org/wiki/File:Spring_Outing_of_the_Tang_Court.jpg
- 作品：传统归张萱（唐，8 世纪）
- 状态：Public Domain / PD-Art
- Commons 说明：底层二维艺术作品已进入公版，美国亦按 Commons 标注为公版。

### 注意

它表现的是宫廷 / 贵族生活，不能用来代表普通唐人的生活水平。

---

## 2. 742 年唐疆域图

**用途建议：**“盛唐的战略空间”或安史前后对比的辅助底图。

- Commons：
  https://commons.wikimedia.org/wiki/File:742nian_Tang.svg
- 日期：现代绘制
- 授权：CC0 / Public Domain Dedication

### 优点

CC0，改图最方便。

### 注意

仍是现代历史地图，不是唐代原图。  
疆界必须按“示意”处理，不应当作精确边界证据。

---

## 3. 1935 年《唐朝 700 年疆界图》

**用途建议：**如果需要一张老历史地图作为视觉资料，可与现代 742 图交叉参考。

- Commons：
  https://commons.wikimedia.org/wiki/File:The_T%27ang_Dynasty_618-906_AD_--_Boundaries_of_700_AD.jpg
- 来源：Albert Herrmann & Georg Westermann, *Historical and Commercial Atlas of China* (1935)
- 状态：Public Domain（Commons 标注）

### 注意

1935 年史学制图，不代表最新研究。  
更适合作为“历史地图本身”的展示，不建议直接承担疆域判断。

**用途建议：**解释“为什么江淮—运河—洛阳 / 关中会成为中晚唐财政生命线”。

- Commons：
  https://commons.wikimedia.org/wiki/File:China-Grand_canal,_Sui_and_Tang.svg
- 授权：CC BY-SA 3.0 / GFDL
- **不是严格 Public Domain**，但允许转载与改编，需要署名并遵守 ShareAlike。

### 注意

如果《气数》未来希望所有自托管图片都尽量 CC0 / 公版，这张可只作为研究参考，最终自己依据权威地理资料重绘。

## 5. 敦煌唐代士兵壁画

**用途建议：**职业军人、边军或“军事职业化”的视觉辅助。

- Commons：
  https://commons.wikimedia.org/wiki/File:Tang_soldiers_-_Dunhuang_mural.jpg
- 内容：敦煌壁画中的唐代士兵
- Commons 标注：底层古代二维作品 Public Domain / PD-Art

### 注意

Commons 该文件的 Source 字段并不理想（Unknown source），虽然古代壁画本身当然已进入公版。

**因此：研究可看；正式文章若使用，最好继续找到对应莫高窟窟号 / 权威博物馆或敦煌研究院出处后再上。**

当前标记：research-only until provenance improved

## 6. 黄巢像（明刻《残唐五代史演义》）

**用途建议：**黄巢章节人物视觉，但必须写清它不是唐代写真。

- Commons：
  https://commons.wikimedia.org/wiki/File:Huang_Chao.jpg
- 图像来源：明刻《残唐五代史演义》
- 创作时间：1644 年以前
- 作者：佚名
- 状态：Public Domain（Commons 标注中国及美国公版）

### 必须写的图注

> 明代刻本中的黄巢想象像，并非唐代同时代肖像。

否则普通读者很容易误认为“这是黄巢本人画像”。

- Commons：

- 授权：CC BY-SA 4.0
- **不是 Public Domain**

### 建议

正式发布更建议：
- 使用它做资料比对；
- 再依据研究内容制作《气数》自己的“约 900 年政治控制示意图”，并明确“控制程度”而不只是画国界。

# 使用优先级

## 可用但有条件

6. 900 年唐地图——CC BY-SA 4.0

## 先研究、不正式使用

7. 敦煌唐兵壁画——底层公版，但当前 Commons 来源链不够干净，需要补窟号 / 权威机构出处。

# 后续还值得找的公版素材

- 唐代税粮 / 绢帛实物（博物馆 Open Access）
- 唐代钱币（博物馆 CC0 / Public Domain）
- 扬州、运河相关考古或古地图
- 唐代驿路 / 漕运文书
- 敦煌或吐鲁番户籍、税契、军籍文书的开放影像

这些图如果找到权威机构 Open Access，比“古装人物图”更有研究价值。
