## 1. 研究包 A｜盛唐为何能盛，也为何产生新风险

### 要回答
- 府兵、募兵、节度使的演变时间线是什么？
- 边疆扩张为何需要更长期、更专业的边军？
- 节度使权力集中究竟是安史前已有趋势，还是战争产物？
- 均田 / 户籍 / 租庸调在什么条件下有效？
- 这些条件在 8 世纪前半叶已经发生什么变化？
- 长安与关中对东部、江淮粮运的依赖在安史前有多深？

### 证据形态
- 制度时间线
- 关键军镇 / 兵力 / 任职结构
- 户籍与课役制度原文
- 漕运与粮食供给数据
- 学界对“战前结构性脆弱”的竞争解释

## 2. 研究包 B｜安史八年到底打坏了什么

不得只列“人口锐减、两京陷落、藩镇坐大”。

### 分项
1. 人口与户籍
2. 农业与核心经济区
3. 财政征收与课役
4. 军事指挥与地方武装
5. 河西 / 陇右 / 西域等战略空间
6. 漕运与交通
7. 中央政治权威

### 每项必须区分
- 战前已存在
- 755—763 直接冲击
- 战争中的临时制度
- 战后延续 / 恢复 / 替代
- 区域差异

## 3. 研究包 C｜租庸调 → 两税法：必须让普通读者算得明白

### 租庸调数据卡
至少核实：
- 课丁范围
- 租：数量、计量单位
- 庸：服役日数、折纳规则
- 调：绢 / 绵 / 布 / 麻标准
- 是否存在地区差别与免役规则
- 天宝户、口、课户、课口数据
- 数据出处与版本差异

### 失配机制
- 户籍多久一造 / 实际执行情况
- 土地买卖、逃户、客户、迁徙
- 均田制与租庸调的关系应如何准确表述
- 安史战争是“导致崩溃”还是“加速已有失配”

### 两税法数据卡
至少核实：
- 780 年制度文本
- 为什么叫“两税”
- 以何种财产 / 土地 / 户等为依据
- 钱与实物的实际关系
- 夏秋纳期
- 商税等是否属于两税本身
- 初行时史载财政规模
- 后续税额是否固定、如何变化

### 禁止写法
- “租庸调就是按人头税”
- “两税法就是改收货币”
- “两税法取消了一切其他税”
- “两税法直接导致农民起义”

除非证据足以支撑。

## 4. 研究包 D｜中央真的拿到了多少钱？地方又留下多少？

这是本轮核心。

### 必须讲清
- 上供
- 送使 / 留使
- 留州
- 三分是否是固定比例
- 谁决定额度
- 不同地区是否执行一致
- 河北三镇等高度自治藩镇是否上供
- 江淮 / 东南财赋区的制度位置
- 元和时期中央如何尝试拆分节度使财权

### 输出
制作“中央—地方财政关系类型表”，至少区分：
- 中央控制区
- 一般藩镇
- 边防藩镇
- 河北高度自治藩镇
- 东南财赋重区

不得用一个“藩镇”词覆盖全部。

## 5. 研究包 E｜盐政：救命财政与新风险

### 核实
- 第五琦、刘晏等制度变化的时间与差异
- 官府控制哪些环节
- 商人承担哪些环节
- 盐利在中央财政中的规模与时期变化
- 盐价及加价问题
- 私盐犯罪与执法强度
- 私盐经营者的社会构成

### 特别问题
“黄巢是盐贩，因此盐政养出了黄巢”只能作为待检验假说。

需要找证据回答：
- 私盐网络是否提供跨地区组织能力？
- 是否提供资本 / 武装 / 地方关系？
- 还是“私盐贩”只是人物履历，被后世过度机制化解释？

## 6. 研究包 F｜为什么中晚唐不是一条直线衰落

必须主动找“恢复”的硬证据：

- 大历、元和等阶段中央财政与军政能力
- 漕运恢复
- 盐政与两税收入
- 元和削藩及其实际边界
- 官僚任命与地方控制
- 市场、南方经济与城市网络
- 唐中央仍能发动哪些战争 / 政策

需要回答：

> 如果它已经“亡了大半”，为什么还能运行一百多年？

## 7. 研究包 G｜社会压力为何越来越容易转化为武装

避免用“农民起义”一词把所有事件压平。

### 研究对象
- 地方盗匪与流民
- 军人 / 戍卒兵变
- 庞勋
- 王仙芝
- 黄巢
- 私盐经营者
- 可验证的灾荒、饥馑、税负与征发事件

### 机制链待检验
社会压力
→ 脱离户籍 / 生产
→ 流动人口
→ 盗匪 / 私盐 / 军人网络
→ 武装组织
→ 跨区域扩张

每一箭都要有证据；不允许因为链条“听起来合理”就连起来。

## 8. 研究包 H｜黄巢为什么和此前动乱不同

### 查明
- 875—884 的路线、规模、关键节点
- 洛阳 / 长安 / 广州及主要财赋区影响
- 是否切断或严重破坏东南—中央财政与运输
- 唐廷具体依靠哪些军镇 / 军事集团平叛
- 黄巢败亡后哪些地区和制度恢复，哪些没有

核心问题：

> 黄巢是摧毁了“新活法”本身，还是摧毁了维持“新活法”的协调网络？

## 9. 研究包 I｜884—907：为什么“平叛成功”后反而更接近灭亡

重点过程追踪：

- 朱温
- 李克用
- 其他关键军事集团
- 神策军与宦官控制
- 皇帝 / 朝廷的人事与军事自主
- 长安 / 洛阳政治中心的实际控制者
- 904、905、907 等关键节点

不得用“军阀混战”四字跳过机制。

需要判断：
- 何时中央失去独立选择军队的能力？
- 何时军事强人开始决定皇帝与朝廷存亡？
- 907 是原因、结果，还是法律形式上的最后一步？
